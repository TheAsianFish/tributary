# BIRD Mini-Dev data

These files are committed so that the schema-linking evaluation and the
replayed benchmark run offline (in CI) without downloading anything. The
databases themselves are never committed: `make bird` downloads them.

| File | What it is | Source | Licence |
|---|---|---|---|
| `mini_dev_pg-2025-07-04.json` | The 500 BIRD Mini-Dev questions with PostgreSQL gold SQL (official labels), unmodified | [birdsql/bird_mini_dev](https://huggingface.co/datasets/birdsql/bird_mini_dev), `archive/bird_mini_dev_2025-07-04/data/mini_dev_pg-00000-of-00001.json` at commit `5b256b5` | CC BY-SA 4.0 |
| `arcwise_plat_sql_only_with_diff.json` | Arcwise-Plat-SQL: corrected SQLite gold for 498 of the questions, unmodified | [uiuc-kang-lab/text_to_sql_benchmarks](https://github.com/uiuc-kang-lab/text_to_sql_benchmarks), `data/` at commit `b83d8a8`; Jin et al., "Pervasive Annotation Errors Break Text-to-SQL Benchmarks and Leaderboards", VLDB 2026 | CC BY-SA 4.0 |
| `corrected_pg.json` | The corrected gold transpiled to PostgreSQL, with each query's verification status | Generated by `make bird` from the file above | CC BY-SA 4.0 (derived) |
| `catalogs.json` | The eleven databases' tables, columns, types and keys as PostgreSQL reports them, with BIRD's column descriptions | Generated by `make bird` from the BIRD Mini-Dev databases (`minidev.zip`) | CC BY-SA 4.0 (derived) |

BIRD: Li et al., "Can LLM Already Serve as a Database Interface? A BIg
Bench for Large-Scale Database Grounded Text-to-SQLs", NeurIPS 2023.
